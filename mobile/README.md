# Ứng dụng di động điểm danh BLE

Mã nguồn Flutter nằm trong thư mục `ble_attendance_mobile/`.

- Giảng viên tạo buổi học, phát beacon, quét sinh viên, xem kết quả và xuất báo cáo.
- Sinh viên tìm buổi học, phát mã nhận diện, theo dõi khoảng cách và chốt điểm danh.

Xem hướng dẫn chi tiết tại `ble_attendance_mobile/README.md`.
