# Bản web (admin + giảng viên) Implementation Plan

> Plan gọn (hành vi + test); mã viết lúc làm theo TDD. Người dùng yêu cầu: import/xuất file nên làm trên web vì điện thoại bất tiện.

**Goal:** Build cùng mã Flutter ra web, phục vụ từ chính backend tại `/app/`, để admin/giảng viên import CSV/Excel (có xem trước) và xuất Excel ngay trên laptop.

**Architecture:** Giữ nguyên toàn bộ màn hình. Chỉ thay các điểm phụ thuộc nền tảng bằng cài đặt theo nền tảng (conditional import): kho token (web dùng `shared_preferences`/localStorage vì `flutter_secure_storage` cần ngữ cảnh bảo mật HTTPS mà LAN dùng HTTP), chia sẻ file (web tải xuống bằng thẻ `<a download>`), URL máy chủ mặc định (web dùng cùng origin). Backend gắn thư mục build vào `/app` nếu có.

## Ràng buộc
- Mobile không đổi hành vi; web không cần BLE/sinh trắc học (chỉ dành cho admin/giảng viên, sinh viên vẫn dùng điện thoại).
- `dart:io` chỉ dùng ở phần chỉ chạy mobile; mã chung không gọi `InternetAddress`/`Platform`/`File` (đổi sang kiểm tra IP thuần Dart).
- Build web ra `backend/web_dist/` (git-ignore); script `backend/scripts/build_web.sh`.
- Backend: `mount_web(app, directory)` chỉ gắn khi thư mục tồn tại; không ảnh hưởng API; không cần CORS vì cùng origin.

## Tasks
1. **Mã chung chạy được trên web:** `normalizeBaseUrl` không dùng `dart:io` (regex IPv4/IPv6/localhost), giữ nguyên toàn bộ test hiện có; `defaultApiBaseUrl` trên web = `Uri.base.origin`; test cho kiểm tra IP.
2. **Kho token theo nền tảng:** `TokenStore` web = `SharedPreferencesTokenStore` (test bằng `SharedPreferences.setMockInitialValues`); mobile giữ `SecureTokenStore`; chọn bằng conditional import (`createTokenStore()`).
3. **Chia sẻ file theo nền tảng:** `FileSharer` web tải file bằng Blob + `<a download>` (`package:web`); mobile giữ share sheet; chọn bằng conditional import (`createFileSharer()`).
4. **Backend phục vụ web:** `app/web.py::mount_web`, gọi trong `main.py` với `backend/web_dist`; test với thư mục tạm (index.html trả về ở `/app/`, API `/health` vẫn hoạt động, không có thư mục thì không lỗi).
5. **Build + kiểm tra:** `flutter build web --release --base-href /app/`, script sao chép vào `backend/web_dist`; chạy thử thật (đăng nhập `A001`, import có xem trước) bằng trình duyệt; README + STATUS.
