# Frontend web React (admin + giảng viên) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (người dùng đã chọn chạy tại chỗ, "native"). Plan gọn: mỗi task nêu hành vi, giao diện hàm và test; mã viết lúc làm theo TDD (xem test đỏ trước). Checkbox `- [ ]` để theo dõi.

**Goal:** Web React cho admin và giảng viên, backend phục vụ tại `/app/`, thay bản Flutter web.

**Architecture:** SPA Vite/React/TS trong `web/`, cùng origin với API. Lớp `api/client.ts` bọc `fetch` (token, lỗi `{detail, code}`, 401); hook TanStack Query theo miền; trang ghép từ component shadcn. Kiểu API sinh từ `openapi.json`.

**Tech Stack:** Vite, React 19, TypeScript strict, Tailwind, shadcn/ui, React Router, TanStack Query, react-hook-form + zod, sonner, lucide-react, Vitest + Testing Library + MSW, openapi-typescript.

**Spec:** `docs/superpowers/specs/2026-10-20-react-web-design.md`

## Global Constraints

- Chỉ tiếng Việt; chỉ vai trò admin và giảng viên (sinh viên thấy trang hướng dẫn dùng app Android).
- BrowserRouter với `base=/app/`; API cùng origin (dev: Vite proxy sang `http://localhost:8000`); không CORS.
- Token JWT trong `localStorage`; 401 với token hiện tại thì đăng xuất; lỗi hiển thị `detail` của server.
- Không dùng `dangerouslySetInnerHTML`; tên file tải về chỉ lấy phần tên cuối (không có `/`, `\`, `..`).
- File import ≤ 2 MB, đuôi `.csv` hoặc `.xlsx`, kiểm tra ở client trước khi gửi.
- Mọi thao tác ghi khóa nút khi đang gửi; xóa/kết thúc/từ chối qua hộp thoại xác nhận.
- Thời gian server là UTC có `Z`; hiển thị theo giờ máy trình duyệt, định dạng `vi-VN`.
- `npm run build`, `tsc --noEmit`, `npm run lint`, `npm test` sạch; không đụng mã Flutter.
- Không push; commit từng task; kết thúc kèm review nhánh.

## Review Focus

- Token hết hạn/ bị thu hồi giữa phiên: mọi trang về đăng nhập, không lặp vòng gọi API (test client).
- Tải lại trang ở đường dẫn sâu (`/app/teacher/classes/<id>`): không 404, giữ phiên (test backend fallback + router).
- Bấm "Xác nhận nhập"/"Lưu"/"Kết thúc" hai lần nhanh: chỉ một request (test từng form/hộp thoại).
- File import sai đuôi, quá lớn, rỗng, có dòng lỗi, nhập chưa được ghi (`committed=false`): báo lỗi rõ, không hiện thành công giả.
- Giảng viên mở buổi của lớp khác hoặc buổi đã kết thúc: lỗi server hiển thị, trang không treo; danh sách rỗng có trạng thái rỗng, không trắng trang.
- Mật khẩu tạm (tạo giảng viên, đặt lại): hiển thị một lần, không lưu vào URL/log/localStorage.
- Admin xóa lớp/môn đang có dữ liệu (409): hiện thông báo server, danh sách không đổi.
